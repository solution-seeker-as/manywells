# Smoothing

## Purpose

Smooth approximations that take the place of non-differentiable functions, so that every row is smooth enough for a gradient-based solver. They change the model's values slightly, so they are part of the model, not of a solver (paper Appendix B.1).

## Interface

| Function | Inputs | Output | Symbolic |
|---|---|---|---|
| smooth max, smooth min | $x$, $y$, $\epsilon$ | a scalar | yes |
| softmax | a vector $y$ | a vector $p$ with $\sum_k p_k = 1$ | yes |
| sigmoid | $x$, $a$, $k$ | a scalar in $(0, 1)$ | yes |

## Equations

### SMO-1 · Smooth max

$$\mathop{\mathrm{smax}}(x, y) = \tfrac12\Big(x + y + \sqrt{(x - y)^2 + \epsilon}\Big), \qquad \epsilon = 10^{-6}$$

$\epsilon$ has the unit of $x^2$. $\mathop{\mathrm{smax}}(x, y) - \max(x, y)$ lies in $(0, \sqrt\epsilon/2]$, largest at $x = y$.

### SMO-2 · Smooth min

$$\mathop{\mathrm{smin}}(x, y) = \tfrac12\Big(x + y - \sqrt{(x - y)^2 + \epsilon}\Big), \qquad \epsilon = 10^{-6}$$

The open-loop model of `v1.0.0` does not use it; v1.0.0's closed-loop controller does, with $\epsilon = 10^{-9}$ (`specs/discrepancies.md`, C-1), and `develop` uses it for dissolved gas (PVT-OIL-7, PVT-OIL-13).

### SMO-3 · Softmax

$$p_k = \frac{e^{y_k}}{\sum_j e^{y_j}}$$

### SMO-4 · Sigmoid

$$s(x; a, k) = \frac{1}{1 + e^{-k(x - a)}}$$

A smooth step from 0 to 1 at $x = a$, of width about $4/k$. Not used by `v1.0.0`; `develop` blends with it in FRIC-6 ($a = 3000$, $k = 0.005$) and PVT-OIL-12 ($a = 50$, $k = 0.5$). `ca_functions.py` also has a double sigmoid, which the model does not use.

## Options

None.

## Safeguards

The softmax does not shift its arguments by their maximum; where it is used (SLIP-7) the arguments are bounded.

## Sources

Paper (B.1), (B.2) and (A.7).
